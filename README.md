# 🛒 E-commerce Website (Frontend Only)
This is a modern, responsive E-commerce website developed using **HTML**, **CSS**, and **JavaScript**. The project is focused purely on the **frontend**, offering a clean user interface and interactive elements typically found in an online shopping platform. It does not include any backend functionality like database or authentication.


## 🌐 Live Preview
👉 [Click here to view the live site](https://soumik-hasansmk.github.io/E-commerce-site-using-html-css-js/)


## 🚀 Features

### ✅ Responsive Layout
- Fully responsive across devices: mobile, tablet, and desktop.
- Uses CSS media queries to ensure smooth UI adaptation.

### 🛍️ Product Display
- Stylish product cards featuring:
  - Product image
  - Name
  - Price (with old price and discount)
  - Wishlist and cart icons

### ❤️ Wishlist UI
- Interactive wishlist icon using Font Awesome.
- Allows users to simulate "liking" or saving a product.

### 🛒 Cart Interface
- Visual shopping cart UI (non-functional but designed).
- Clean icon representation for adding items.

### 🔝 Navigation Bar
- Fully responsive navbar.
- Dropdown menus for better navigation.
- Mobile menu toggle for smaller screens.

### 🎨 UI Design
- Clean, modern design using only **HTML and CSS**.
- Minimalistic and easy to read.
- Color scheme suited for shopping platforms.

### 💻 JavaScript Interactivity
- DOM manipulation to handle basic UI events.
- navbar toggle, and more.
